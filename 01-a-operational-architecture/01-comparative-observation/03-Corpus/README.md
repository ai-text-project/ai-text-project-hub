# Corpus

**Comparative Observation Methodology v0.1 (Provisional)**

---

# Overview

This folder defines the Corpus layer of the Comparative Observation Methodology.

The Corpus layer specifies the research resources that constitute the objects of comparative observation.

While the previous layers establish the methodological architecture, principles, and comparative framework, the Corpus layer defines how research resources are organized, classified, and maintained for systematic observation.

The Corpus therefore serves as the operational foundation upon which comparative observation is performed.

---

# Purpose

The purpose of this folder is to establish a structured research corpus that supports consistent comparative observation.

Rather than treating research resources as isolated documents, the Corpus layer organizes them into a coherent collection that enables systematic comparison across multiple observations.

A well-defined corpus improves reproducibility, consistency, and long-term methodological development.

# Relationship with Adjacent Layers

The Framework layer defines the comparative structures that organize observation.

The Corpus layer supplies the research resources to which those structures are applied.

The Observation layer subsequently performs systematic comparative observation using the organized corpus.

```
Framework

        │

        ▼

Corpus

        │

        ▼

Observation
```

Framework defines the organizational structure.

Corpus organizes the research resources.

Observation performs systematic comparative analysis.
