# Media Assignment Framework

**Framework Version:** v1.0 (Provisional)

---

# Purpose

This document defines the principles used to assign appropriate communication media within the Research-to-Society Projection Architecture.

The objective is not to prioritize particular communication platforms.

Instead, the framework establishes how completed Research Packages are matched with communication media according to audience, communication objectives, and projection strategy.

Media Assignment therefore follows Projection Design rather than determining it.

---

# Position within the Projection Architecture

Media Assignment operates after:

- Research Package selection
- Audience Architecture
- Projection Strategy
- Phase Transformation Strategy

The framework determines the most appropriate communication environment before production begins.

Research Package

↓

Audience Analysis

↓

Projection Strategy

↓

Phase Transformation

↓

Media Assignment

↓

Production

---

# Fundamental Principle

Communication media are selected according to communication objectives rather than popularity.

The Bridge Layer therefore begins with:

Who should receive the research?

before asking:

Which media should be used?

Media serve the projection strategy.

They do not define it.

---

# Media-independent Projection

Projection is independent of communication media.

The same Research Package may be projected through multiple media without changing the underlying research.

Different communication products therefore originate from the same projection architecture.

# Media Selection Criteria

Media Assignment considers multiple factors.

Typical criteria include:

- audience characteristics
- communication objectives
- expected communication depth
- interaction requirements
- continuity of engagement
- relationship to existing Research Packages

Media are therefore selected systematically rather than individually.

---

# Multiple Media Assignment

One Research Package may generate multiple communication products.

For example:

Research Package

↓

Meta Visual

↓

Medium Article

↓

Enterprise Presentation

↓

Dialogue Demonstration

↓

Educational Material

Each communication product represents a different projection of the same research.

---

# Relationship to Production

Media Assignment concludes before production begins.

Production roles receive:

- assigned media
- projection objectives
- transformation strategy

Content creation remains outside the responsibility of the Bridge Layer.

---

# Future Communication Media

The framework intentionally remains media-independent.

As new communication environments emerge, additional media may be incorporated without modifying completed Research Packages.

The architecture therefore supports continuous expansion.

---

# Summary

Media Assignment connects Projection Strategy with communication production.

Rather than selecting media independently, the framework assigns communication environments that best support the intended projection while preserving methodological integrity across all communication products.
