# Purpose

This document externalizes the hierarchical organization observed within the representative SOAR resources.

Its objective is not to classify every component of the SOAR architecture.

Instead, it identifies the primary organizational layers that emerge from the Structural Skeleton while preserving the overall structural continuity.

Accordingly, this document provides the first hierarchical projection of the SOAR architecture.

# Preliminary Layer Organization

The current observation suggests that the SOAR architecture may be organized into the following hierarchical layers.

---

## Layer 1 — External Interaction Layer

Responsible for the interaction between the cognitive architecture and its external environment.

Representative structural functions include:

- Environment
- Perception
- Action

This layer represents the interface between the internal architecture and the external world.

---

## Layer 2 — Internal Representation Layer

Responsible for maintaining the current internal cognitive state.

Representative structural function:

- Working Memory

This layer serves as the central organizational representation supporting subsequent cognitive processing.

---

## Layer 3 — Cognitive Organization Layer

Responsible for organizing internal reasoning and behavioral selection.

Representative structural functions include:

- Decision Process
- Operator Application

This layer transforms the current internal representation into executable behavioral organization.

# Structural Characteristics

The present observation suggests several hierarchical characteristics.

- External interaction is separated from internal cognitive organization.
- Working Memory functions as the central representational layer.
- Decision-making and operator application appear within a common organizational layer.
- Behavioral execution reconnects the architecture with the external environment.

These observations remain provisional and may be refined during subsequent representation stages.
