# Shared Markdown Knowledge Layer

**Version:** v1.0 (Provisional)

---

# Purpose

This document defines the Shared Markdown Knowledge Layer employed throughout the Research Program.

The purpose of this layer is to provide a persistent knowledge infrastructure that can be shared, interpreted, and continuously refined by both human researchers and AI instances.

Unlike raw dialogue logs, this layer consists of progressively structured Markdown assets that function as the primary operational knowledge base of the Research Program.

---

# Background

The Research Program has progressively evolved a workflow in which dialogue histories are transformed into reusable Markdown-based research assets.

These assets are not merely archival documents.

They function as persistent semantic resources that support subsequent research activities, including:

- structural observation
- methodology development
- paper assembly
- research mapping
- presentation development
- operational architecture
- enterprise collaboration

As the Research Program expanded, these Markdown assets gradually became the principal working layer shared between human researchers and AI instances.

Raw Dialogue

↓

Each stage produces reusable Markdown assets.

Rather than repeatedly returning to raw dialogue histories, subsequent research activities primarily operate on these compiled Markdown resources.

---

# Shared Human–AI Knowledge Layer

Within the Research Program, GitHub functions as more than a repository.

It provides a persistent Markdown knowledge layer that enables both humans and AI instances to:

- access shared research assets
- refine existing knowledge
- extend previous observations
- maintain long-term semantic continuity
- collaboratively develop new research structures

The Markdown layer therefore serves as a common semantic workspace.

---

# Structural Correspondence with the LLM-Wiki Concept

During subsequent review, the workflow proposed by Andrej Karpathy under the concept of "LLM-Wiki" was found to exhibit several structural similarities.

These include:

- preservation of raw source materials
- compilation into persistent Markdown knowledge
- shared human–AI knowledge resources
- continuous refinement of the shared knowledge layer

The Research Program does not claim to implement LLM-Wiki.

Rather, the current workflow independently exhibits several structural characteristics corresponding to the workflow described by the LLM-Wiki concept.

The relationship is therefore interpreted as a Structural Correspondence rather than an implementation.
